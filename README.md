# Project 14 named WTWR 2026

WTWR in 2026 is a weather-based clothing recommendation app that suggests what to wear in 2026 based on the current weather conditions when users can sign up, sign in and sign out.

# My Features Section are

- Temperature, location, date and time
- Weather-based clothing recommendations
- Signing out, in and up

# React Routing and State Management

I am implementing in this project the registration and authorization with the temperature and city also  
adding the current User context, the editing profileand the likes and deslikes to finally implementing the sign up, sign in and sign out.

React context is the way to do not pass data as props through multiple layers of components so that the Router can ensure that my url is synchronized with the inside of the application, share links to views, and help to see different content.

Mock API server being a tool that help on returning generated responses to a request

# The Technologies Section I have used

- React
- React Router
- React Context
- CSS
- json-server
- Vite

# Steps to run my project

Created new folder WTWR for both projects to download my new project in vscode.
Start my React app by: "cd se_project_react" and "cd se_project_express"
The exact json-server command:"json-server --watch db.json --id \_id --port 3001"
and Local: http://localhost:3000/
